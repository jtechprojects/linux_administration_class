# CIS-245 Linux Administration

This repository documents my hands-on coursework for CIS-245 Linux Administration at Northern Essex Community College during Fall 2026.

Throughout this course, I have been learning how to install, configure, manage, and troubleshoot Linux servers using Ubuntu and CentOS Stream 10.

## Coursework

- **Linux Server Setup:** Creating and configuring Linux virtual machines using Oracle VirtualBox.

- **Packages and Updates:** Managing software installations, repositories, and services using APT and DNF.

- **Text Processing:** Practicing Grep, AWK, and Sed commands to search, filter, and modify text.

- **Networking and Bash Scripting:** Examining network configurations and creating scripts to collect network information and assist with troubleshooting.
