# ACME-6390 — Report Server Troubleshooting Lab

## Project Overview

This project was completed as part of my CIS-245 Linux Administration coursework. I used CentOS Stream 10 and Ubuntu 26.04.1 LTS virtual machines to troubleshoot server issues, develop an automated Bash diagnostic script, and practice Linux recovery procedures.

## Project Files

- **securitylabpart2.pdf** — Complete lab report containing troubleshooting steps, screenshots, results, and citations.
- **system_diag.sh** — Bash script for collecting system diagnostics on CentOS and Ubuntu.

## Skills Demonstrated

- Linux server troubleshooting
- Bash scripting and automation
- Systemd service management
- Network troubleshooting
- Cron job scheduling
- Emergency and recovery mode
